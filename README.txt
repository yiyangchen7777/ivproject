README - Run Instructions

Follow these steps to run the project's R script:

1. Install R (version 4.0 or newer recommended).
2. Open a terminal and change into the project directory, for example:
   cd /path/to/ivgroupproject
3. Execute the script with:
   Rscript app.R
   # or, inside an interactive R session:
   source("app.R")

The script will run every step defined in app.R and print the output in the terminal or R console. If R reports missing packages, install them with install.packages() and rerun the script.
